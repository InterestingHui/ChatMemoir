# Quick Task 260826-5h3: GUI 加载当前登录微信账号

## What

WSL/Linux 下 GUI「开始解析」始终展示 `last_db_dir` 指向的旧账号解密数据，切换微信登录账号后无感知。

## Root Cause

`gui/decryption.py:_try_load_existing_db_dir()` 把 config `last_db_dir` 排候选第一位并无条件返回。

## Fix

- 新增 `_detect_live_wechat_uid()`：扫 `/mnt/c/Users/*/xwechat_files/wxid_*/db_storage` 热点 db（session/message_fts/message_0/contact）mtime，最新者=当前登录账号；uid 去尾部 `_xxxx` 后缀；24h 无写入返回 None（退回旧行为）。
- `_try_load_existing_db_dir()` 候选排序改为：当前登录账号 > last_db_dir > 其余；当前账号无解密数据时 raise 明确报错，不再静默展示别的账号。
- `_on_decrypt_done()` 修复 info.json 读取：路径回退到 `db_dir/../info.json`，键名 `username`（原 `uid` 永远取不到），昵称为空时回退目录名。

## Verification

`tests/test_gui_live_account.py`（headless stub，真实 WSL 数据）：
- `detect_live_wechat_uid() -> 'wxid_ttlo1sb5pyh811'`（与 /mnt/c 一小时内 105 个文件写入的证据一致）
- last_db_dir 指向旧账号时，fallback 返回 `decrypted/wxid_ttlo1sb5pyh811/db_storage` ✓
- 当前账号无解密数据时 raise RuntimeError ✓

## Deviations

- 未用 worktree 隔离：executor 需要主树里 gitignored 的 `decrypted/` 真实数据做验证，等价 `use_worktrees=false` 路径。
