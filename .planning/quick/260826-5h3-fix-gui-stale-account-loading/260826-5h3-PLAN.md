## Root Cause

`gui/decryption.py:_try_load_existing_db_dir()` 把 config 的 `last_db_dir` 排第一无条件返回，导致 WSL 下切了微信账号后 GUI 仍加载旧账号的解密数据（`wxid_ka89oj7i1mz622`），而不是当前登录的 `wxid_ttlo1sb5pyh811`。

## Tasks

### Task 1: 新增当前登录账号探测 + 调整回退加载优先级

- **files**: `gui/decryption.py`
- **action**:
  1. 新增 `_detect_live_wechat_uid()`：WSL 下扫描 `/mnt/c/Users/*/xwechat_files/wxid_*/db_storage`，取 db 文件 mtime 最新者作为当前登录账号，uid 去掉尾部 `_xxxx` 后缀。
  2. 重写 `_try_load_existing_db_dir()` 候选排序：当前登录账号的解密目录 > `last_db_dir` > 其余解密目录。
  3. 修复 `_on_decrypt_done()` 读 info.json 的路径（实际在 db_storage 父目录）和键名（`username` 而非 `uid`）。
- **verify**: 单测/冒烟确认 `_try_load_existing_db_dir()` 返回 `decrypted/wxid_ttlo1sb5pyh811/db_storage`。
- **done**: 回退加载返回当前登录账号的解密目录；账号标签从 info.json 正确读取。
