# ChatMemoir 语音转文字（HTML 提取不漏语音）— 交接文档

## 解决了什么问题

HTML 导出时，语音消息之前只导出为 `voice/年-月/*.mp3` + 播放器气泡；只有微信里点过「转文字」的语音（存进 voicetrans / Audio2Text.db 缓存的）才有文字。其余语音在**复制/提取文本时直接丢失**。

现在的方案：**批量转写工具把语音转成文字写进缓存库 → 导出器自动读取渲染**；未转录的语音在页面里显示明确占位标注，不再静默消失。

## 组成部分

| 文件 | 作用 |
| --- | --- |
| `voice2text_batch.py`（新增） | 批量转写：SILK→pysilk 解码→Whisper→写回 `Audio2Text.db`，增量可续跑，台账 JSONL |
| `scribe/exporter_base.py`（+4 行） | ffmpeg 查找回退：找不到自带 ffmpeg.exe 时用系统 `ffmpeg`（WSL 导出语音必需） |
| `scribe/exporter_html.py`（+4 行） | 未转录语音兜底：`audio_text` 为空时填充占位文案，复制时可见 |
| `3-exporter.py` batch 模式（+18 行） | 导出前尽力回填（读缓存，不阻塞），并把 message_types 改为全类型（此前 batch 模式只导文字/图片/链接！） |
| `data/voice_ledger.jsonl` | 转写台账：每条语音的 msgSvrId、归属 uid、时长、转写耗时、状态（OK/EMPTY/FAILED）、全文、时间戳分段 |

## 快速上手（WSL Ubuntu，/home/ChatMemoir）

依赖（本机已具备）：python3.12、openai-whisper、pysilk、numpy、torch、ffmpeg。全新环境安装：

```bash
pip install openai-whisper pysilk numpy torch
sudo apt install ffmpeg   # 仅 HTML 导出语音 mp3 需要；纯转写走 pysilk 无需
```

常用命令：

```bash
cd /home/ChatMemoir

# 1) 看待转写规模（不加载模型）
python3 voice2text_batch.py --uid wxid_9zv9emyoyx7y12 --smoke

# 2) 转写某个联系人的语音（增量，可随时 Ctrl+C，重跑自动续）
python3 voice2text_batch.py --uid wxid_9zv9emyoyx7y12

# 3) 全库转写（挂机跑；当前全库待转 ~1.1 万条，约 4-6 小时）
python3 voice2text_batch.py

# 4) 导出 HTML（读同一份缓存；GUI 导出和 3-exporter.py 均可）
python3 3-exporter.py decrypted/wxid_ttlo1sb5pyh811/db_storage wxid_9zv9emyoyx7y12
```

> 注意：`--uid` 用 wxid（Msg 表按 md5(wxid) 命名，工具内部自动换算）；GUI 批量导出（Windows Python）与 `3-exporter.py batch` 共用 `decrypted/<uid>/db_storage/Audio2Text.db`，**两边转写结果互通**。

## GUI 一键转写

主界面「导出聊天记录」一栏新增 **「一键转写」** 按钮（2026-09-18）：

1. 解密并加载联系人后，左侧选中任一联系人
2. 点「一键转写」——后台自动把该联系人**所有还没文字的语音**转写入库（Whisper small）
3. 状态栏实时显示进度（`转写中: 15/40 成功=14 空=1 失败=0`），完成弹窗给汇总
4. 转写期间导出/批量导出按钮自动禁用，防并发
5. 完成后联系人详情的「已转写 x/y」自动刷新；此时再导出 HTML/TXT，语音就带文字

规则与命令行版一致：增量（已有的跳过）、失败不写缓存可重试、空语音写占位、台账追加到 `data/voice_ledger.jsonl`。

## 转写质量与速度（实测）

- 模型：whisper `small`（CPU，~470MB，首次自动下载到 `~/.cache/whisper`）
- 速度：0.6–0.9 条/秒（CPU 4 线程，短语音占比高时更快）
- 质量：中文（含繁体）对话可读性好；专有名词偶有谐音错字（如「转让费→转費/挣账」），清理时建议人工抽查关键字段
- 台账里每条带 `segments`（start/end/text 秒级分段），可定位到原文时间点

## 常见问题

- **转写了一半中断** → 直接重跑，已完成的不重复
- **某条 FAILED** → 台账里有 error 原因；FAILED 不写缓存，修复后重跑自动重试
- **EMPTY 是什么** → 解码成功但没有语音内容（静音/极短），已写空文本进缓存，页面显示占位
- **想换更高质量的模型** → `--model medium` 或 `--model large-v3`（更慢，CPU 上不建议 large）
- **GUI 导出还是没有文字** → 确认 GUI 用的账号目录和转写的 `--db` 是同一份 `decrypted/<wxid>/db_storage/`

## 修改指南

- 占位文案：`scribe/exporter_html.py` 搜 `[语音未转录`
- 转写语言：`voice2text_batch.py` 的 `transcribe_one(..., language='zh')`；其他语言改 `None` 让 Whisper 自动检测
- 台账路径：默认 `data/voice_ledger.jsonl`，`--jsonl` 可改
